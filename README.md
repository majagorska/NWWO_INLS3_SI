## Uruchamianie
**Program uruchamia się za pomocą Docker Compose według poniższych komend:**

```
Bash
docker compose up --build
Ręczne budowanie obrazu Dockera:
```
```
Bash
docker build -t moja-aplikacja .
docker run -p 3000:3000 moja-aplikacja
```
